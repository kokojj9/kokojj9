# 박재인 | 풀스택 엔지니어

AI 개발 환경을 직접 구축해 혼자서 여러 시스템을 개발·운영하는 풀스택 엔지니어입니다.

2인 개발 조직에서 B2B 커머스 플랫폼, 신규 이커머스, 사내 업무 플랫폼, 외부 기관 ERP 연동을 개발하고 운영합니다. 요구사항 정리, 설계, 개발, 배포, 운영을 담당하고있습니다.

## 개발 방식

- 커스텀 스킬, 훅, 서브에이전트로 개발 환경을 구성해 코드 작성·리뷰와 산출물 문서 작성을 자동화했습니다.
- AI 에이전트의 반복되는 실수를 유형별로 정리해 작업 규칙으로 만들고, 여러 CLI에 같은 규칙을 적용했습니다.
- 설계 문서는 다른 AI 모델로 교차 검토하고, 구현은 테스트 코드와 함께 진행합니다.
- 메일과 메신저로 들어오는 업무 요청을 한 곳에 모아 요구사항으로 정리하는 업무 요청 관리 도구를 만들어 쓰고 있습니다.

## 주요 프로젝트

- **내부망 ERP 연동**

  내부망을 외부에 노출할 수 없는 제약을 DMZ 중계 서버 구조로 해결했습니다. 상대 기관과의 기술 협의, 연동 규격 협의, 설계, 구현, 시연을 단독으로 수행했고 현재 실서비스로 운영 중입니다.

- **커머스 플랫폼 자사 전환**

  외주사가 운영하던 B2B 커머스 플랫폼을 인수인계 문서 없이 넘겨받아 자사 운영으로 전환했습니다. 이후 주문, 결재, 결제, 정산, 월말 마감을 운영하며 고객사 전용몰 10곳을 구축했습니다.

- **B2B 이커머스 플랫폼 재개발**

  외주 개발된 B2B 쇼핑몰을 인수해 2026년 4월 정식 오픈했고, 이후 결제, 공급사, 관리자, 견적 영역을 다시 개발해 운영하고 있습니다. (Spring Boot, JPA, MariaDB)

  - 결제·정산: 후불결제 입금 상태 관리, 세금계산서 신청과 알림 메일
  - 공급사: 입점 공급사용 관리 모듈 신규 개발 (공급사 등록, 계정 발급, 상품 일괄등록, 주문 처리)
  - 관리자: 회원, 상품, 카테고리, 주문, 전시, 게시판, 문의 화면 개편과 대시보드·통계 화면 5개 추가
  - 견적: 견적 요청 흐름과 견적서 개선
  - 운영: 백업 체계 구성, 배포 설정 점검, 외부 상품 공급사 연동 점검

- **사내 업무 플랫폼**

  전담 기획자 없이 업무 흐름을 직접 분석해 기능을 정의하고, 영업 데이터를 통합해 통계로 영업 기회를 발굴하는 사내 플랫폼을 구축했습니다. AWS EC2와 GitHub Actions 자동 배포를 직접 구성해 운영하고 있습니다.

- **업무 자동화**

  외부 공고 데이터 수집, 영업 기회 판정, 메일 발송을 자동화했습니다.
